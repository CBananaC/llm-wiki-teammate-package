依兩項回饋修改上一版草稿：（1）說明卡移除 VS Code 風格的 Skill 視窗，只保留標題與摘要文字；（2）不再用簡化版的自製圖表／文書面板，改為直接以 <iframe> 內嵌真正的 platform-interface-replica.html（真實工具列、真實四線圖表引擎、真實文書與 AI 分析區）。

取捨說明：內嵌的是平台介面複本「原樣」——它目前載入的示範文書是硃42（徐嗣曾，為彰化諸羅俱失及撥兵等緣由事），並非上一版草稿使用的孫士毅奏摺／上諭配對。因為硃42 沒有對應「奉上諭標記／日期／引文／作者」這四項辨識線索的標記，所以本頁的編號導覽（下方說明卡）目前只獨立示範「逐項切換說明文字」的步進互動，尚未連動到內嵌工具內部的圖表節點或文書標色——這點與圖表／文書面板皆為即時渲染的真實引擎有關，兩者資料結構不同，無法直接套用舊版的標色點擊邏輯。若要讓編號真正對應到內嵌工具裡的圖表節點與文書標色，需要另外準備一份以孫士毅奏摺／上諭為主角、且格式與 part-1-interface-data.js 相符的示範資料，我可以在確認方向後再處理。

四項線索文字逐字取自現有 part2-yu-response-bars.js（與前一版草稿相同，已用 SHA-256 核對，未新增、未改寫文字）。內嵌的平台介面複本則直接使用真實檔案 platform-interface-replica.html／part-1-interface.css／part-1-interface.js／part-1-interface-data.js，未作任何修改。
