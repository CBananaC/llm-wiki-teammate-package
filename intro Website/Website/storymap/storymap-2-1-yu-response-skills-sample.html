清代奏摺與上諭分析平台・2-1 辨識奏摺所回應的上諭

2.1 線索說明卡：50% 文字說明 ＋ 50% Skill 技能視窗並排（等高、免捲動）

線索說明卡置於視覺圖表與雙文書面板下方。左側 50% 顯示線索說明文字，右側 50% 顯示 VS Code 風格的精簡 Skill 視窗（等高對齊，去除冗餘標籤與文件標題，文字精簡免捲動），並精確高亮當前線索對應的 Skill 規則。切換線索時即時同步更新。

2.1示範

辨識奏摺所回應的上諭

一種深層的通信關係是：有些奏摺會回應官員收到的上諭。平台會使用「上諭—回應配對」Skill，根據引述標記、日期、引文及奏摺作者等線索，辨識這段通信關係。

① 「奉上諭」等引述標記 ② 上諭的發出日期 ③ 上諭引文 ④ 奏摺作者
01

「奉上諭」等引述標記

官員在奏摺中回應皇帝的上諭時，通常會使用「奉上諭」、「奉聖諭」、「聖諭」、「奉廷寄」、「欽奉諭旨」或「欽奉上諭」等引述標記；部分回覆也會先用「接奉」、「接准」或「敬奉」等標記，注明自己收到上諭的日期。平台會先利用 Python 從原始文書中擷取這些標記，作為辨識奏摺是否回應上諭的第一項線索。
