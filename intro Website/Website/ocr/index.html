01—02 · 先建立共同語言

先把影像變成可讀的文字

OCR 不是把史料「變得正確」，而是把影像中的字元轉成可以搜尋、編輯和再處理的候選文本。接下來的結構化，才會讓每份文書的來源、欄位與正文有清楚的位置。

0原始影像不被覆蓋

OCR 產物是 derived data，必須與原始掃描檔分開保存。

1

甚麼是 OCR？

OCR（Optical Character Recognition，光學字元辨識）是一種將影像中的文字辨識並轉換為機器可讀文本的技術。

影像 → 機器可讀文本
2

使用 OCR 的原因

由於 AI 無法直接讀取掃描影像形式的歷史材料，研究者因此需要先利用 OCR 將史料轉換為可編輯及可搜尋的文本，再整理成結構化資料，後續才能用 AI 進行資訊提取和分析。

可搜尋 · 可編輯 · 可追溯

03 · 選擇 OCR 工具
3

PaddleOCR

研究者可使用 PaddleOCR 作為 OCR 的工具。PaddleOCR 是由百度開發，具有以下優點：

  • 能夠辨識掃描影像或 PDF 中的中文文字，並支援版面分析。
  • 中文辨識準確率高，而且辨識速度快。
  • 開源且免費，支援本地部署，可離線運行。

運用 Agentic AI 使用 PaddleOCR

PaddleOCR 通常透過 Python 在本機安裝和運行。然而，研究者即使不具備編程能力，亦可透過自然語言指示 Agentic AI 安裝 PaddleOCR，以及撰寫執行 OCR 的 Python 代碼。

05 · OCR 前先準備好材料
5

OCR 前的材料準備

OCR 所處理的材料通常為 PDF 或 JPG、PNG、TIFF 等影像檔案。因此，如果史料為紙本書籍，研究者可先查找是否已有可合法使用的電子版本，若沒有，則需以掃描器或相機把書頁數位化，轉換為 PDF 等形式的影像檔案。

先確認使用權研究者應遵守所在地的版權法規及資料庫使用條款，優先使用公有領域、已獲授權或依法可供研究使用的材料。
06 · 先看懂版面，再寫規則
6

檢視史料的版面及格式

要使用 PaddleOCR，研究者首先需要檢視史料的版面及格式，以便要求 Agentic AI 撰寫合適的 Python OCR 規則。

01字體類型：印刷或手寫
02文字方向：橫排或直排
03文書結構：標題、正文、批註、硃批、頁碼
不要先問「AI 能不能讀」；先問「研究者要保留哪些結構」。

輸出格式：JSON

              
除了設定版面辨識的規則外，研究者亦應要求 Agentic AI 把 OCR 結果輸出為 JSON 的格式。

              
JSON 是一種常用的結構化資料格式，能以「欄位－內容」的方式儲存資料，方便 Python、AI 及網站讀取和處理資料，亦有利於後續的搜尋、分析和視覺化。

10 · 小量測試，再批次處理

          

            

              
10

              
OCR 測試

              
完成 Python OCR 程式後，研究者可注意 Agentic AI 執行 OCR，但建議先以 1 至 5 頁史料作為測試。

              
研究者應檢查 OCR 能否正確辨識文字和格式，並根據測試結果修正 Python 規則。若沒有明顯錯誤，便可開始進行完整史料的 OCR。

              
為避免程式中斷和方便檢查，建議把大型史料分批處理，例如每次處理 50 頁，完成一批後先檢查結果，再繼續處理下一批。
