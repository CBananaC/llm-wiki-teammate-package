「執行 AI Skills 的方法」新增正方形視覺元素 — AI Chain 環狀掃描動畫草稿

放在「執行 AI Skills 的方法」文字卡右側的新視覺元素：六個步驟畫成一圈小圓點，依序逐一「填滿」代表 一個步驟做完才開始下一個；因為「文書總結、分段」並不是「輸出結構化 JSON」的下一步， 第 6 點與第 1 點之間刻意不連接，圓圈下方留一個缺口。中央是一個 VS Code 風格的 JSON 視窗， 掃描光暈會在每一步跟著該步驟的小圓點填滿速度，從頭掃到尾一次，讓人感覺「這一步正在分析文書」。

  • 六個步驟文字逐字取自網站現有的 #part-3-ai-chain-chart：文書總結、分段 → 抽取事件及官員行動 → 追溯資訊來源 → 抽取上諭中皇帝對奏摺的回應 → 抽取後續官員的回應 → 輸出結構化 JSON，未新增或更動任何步驟名稱。
  • 圓點本身不放文字（版面太小），改用小圓點旁的圖例對應數字，滑鼠不需要互動也能看懂目前跑到第幾步。
  • 動畫是純時間軸驅動（performance.now() 取模），不是逐格用 setInterval 累加狀態，所以分頁切走再切回來不會卡住或跳格。
  • 已加入 IntersectionObserver（畫面外暫停）與 prefers-reduced-motion（改成靜止的示意畫面，不跑動畫）。

為減少重複操作，研究者可要求 Agentic AI 撰寫 Python代碼，將多個 AI Skills 串聯成自動化的分析流程 （Chain）。程式會逐份讀取結構化文書，依序執行各項 AI Skills，並自動將結果儲存至 JSON 檔案，直至完成所有史料的分析，
