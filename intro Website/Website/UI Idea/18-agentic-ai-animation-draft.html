之後加動畫時的規劃（目前尚未實作）

1

Terminal 逐行輸出：每隔一段時間多顯示一行指令／結果，最後一行的游標閃爍，全部顯示完後淡出重新開始（loop）。

2

VS Code 逐字輸入：程式碼一個字一個字「打」出來，搭配閃爍游標，可與 Terminal 稍微錯開時間，製造「同時在忙」的感覺。

3

寵物機械人打字動作：頭部做極輕微、規律的上下擺動，臉部 >_ 可以偶爾眨一下（壓扁再彈回），暗示正在專心操作鍵盤。

整體：全部用 CSS @keyframes 純動畫（無需 JS），檔案仍是單一 .png/.gif 大小的靜態替代方案也可以另外準備，避免動畫在舊瀏覽器或列印時失效。
