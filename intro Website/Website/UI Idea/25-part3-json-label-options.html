9 輸出格式：JSON — 欄位標籤按鈕設計選項

目前 .part3-json-label 只有細邊框＋純白底，四個方案都保留原本「點擊後對應 JSON 那一行反白並保持選取」的行為，差別只在按鈕本身的視覺語言。滑鼠移到按鈕上可看 hover，點擊可看 clicked／selected 狀態（此範例點擊會切換選取，模擬實際行為）。

基準（目前網站上的樣式）BEFORE

純白底、細邊框、方形直角；hover 時邊框變橘、加陰影；選取時整塊填深綠。使用者反映「按鈕標籤很醜」。

方案 A — 圓角膠囊（Pill）推薦

實心淡底膠囊，字重加粗、字級略放大，去除邊框改用背景色深淺表達狀態。選取時整顆填深綠色並帶陰影，點擊時有輕微縮放回饋。最貼近一般網站「篩選標籤」的常見語彙，最容易辨識可點擊。

  "zhu_text": "依議欽此",   "zhu_date": "乾隆五十二年正月",   "pages": "3"

適合：想要最直覺、最不需要說明就懂「這是可切換的標籤」。

方案 B — 描邊卡片 ＋ 指示點層次分明

維持白底與邊框的「文件感」，但加上一顆小圓點作為狀態指示（未選取：灰點；hover／選取：橘點並帶暈光）。選取時邊框與底色轉為淡橘，呼應 --accent 色。比方案 A 更沉穩、更貼近目前网站已有的「卡片」語彙。

適合：想要保留目前「卡片＋邊框」的文件質感，只是把它做得更精緻，而非換成完全不同的形狀語言。

方案 C — 底線頁籤（Underline Tab）最輕量

拿掉背景與邊框，只用文字顏色深淺＋底線表達狀態，很像分頁籤（tab）。視覺最安靜、不會搶走 JSON 視窗的注意力，但可點擊性稍弱，需要 hover 才明顯感覺到互動。

適合：如果覺得目前按鈕視覺太重、想要更接近「純文字索引列」的感覺。

方案 D — 沿用網站黃色重點色品牌一致

未選取時是稍微精緻化的白底卡片（圓角、更柔和陰影）；選取時改用網站既有的 --yellow 強調色填滿，呼應網站其他地方（如摺頁效果指示）已經用黃色表達「目前焦點」的視覺語言，讓這個區塊感覺是網站設計系統的一部分而非獨立元件。

適合：想要選取狀態更醒目突出，且與網站其他黃色強調元素呼應。
