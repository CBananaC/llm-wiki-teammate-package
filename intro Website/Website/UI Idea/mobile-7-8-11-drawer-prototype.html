手機版原型：7／8／11 的抽屜式版面

這是獨立的原型檔，還沒有改動正式網站的任何檔案。用來先確認手機版的互動方式是否合用，確認後我再移植到 storymap.css／storymap.js。

  • 資訊面板為主體：手機上直接顯示右半欄的內容（特徵說明 → AI Prompt → Python → JSON），不再左右並排。
  • 左側拉手：畫面左緣中間的「史料」拉手，點一下把史料圖從左邊拉出來。
  • 兩段式拉出：預設只拉出約三分之二寬，剛好看到書頁右側的關鍵欄位；按「整頁」可拉到滿版看完整頁面，圖片本身也可左右／上下拖動。
  • 頂部特徵篩選列：取代桌面版浮在圖上的標籤，改成可橫向滑動的膠囊按鈕；選哪一項，下面的說明與抽屜裡的標示圖就跟著換。
