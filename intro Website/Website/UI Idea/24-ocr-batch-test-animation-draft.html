10

OCR測試

完成 Python OCR 程式後，研究者可注意 Agentic AI 執行 OCR，但建議先以 1 至 5 頁史料作為測試。研究者應檢查OCR能否正確辨識文字和格式，並根據測試結果修正 Python 規則。若沒有明顯錯誤，便可開始進行完整史料的 OCR。為避免程式中斷和方便檢查，建議把大型史料分批處理，例如每次處理 50 頁，完成一批後先檢查 結果，再繼續處理下一批。

動畫流程（每一輪）

1

單頁測試（1頁）：一頁半透明的手抄本置中放大，藍色掃描線由上往下掃過，頁面隨之變成完整彩色。

2

翻成 JSON：同樣大小的 VS Code 風格視窗翻面蓋上，裡面是這份文書真實的 JSON 內容。

3

閱讀＋驗證：一副會反光的眼鏡浮現在視窗上，亮光掃過整段文字，接著彈出綠色勾號代表通過檢查。

4

轉為批次（50頁）：徽章跳成 50頁，畫面變成 2×2 並持續往下捲動，每一格用不同的頁面和不同的文書 JSON，錯開時間重複同一套流程。
