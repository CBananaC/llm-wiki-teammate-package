# UI ideas — 第一部分

## Purpose

Explain the platform’s interface by letting the student recognise the main regions before reading detailed terminology.

## Proposed experience

Under the `1. 平台的整體介面` cover, show one large replica of the sample review tool instead of dividing the overview into several separate cards. The replica should be recognisable as the actual sample interface, but can be simplified enough that the four regions are immediately legible.

Place four numbered highlight areas directly on the replica:

1. `導覽列`
2. `時間與關係圖表`
3. `原始史料區`
4. `AI 分析區`

When a user clicks one highlight:

- the selected region receives a stronger border or glow;
- the other regions become slightly quieter;
- a floating label appears beside the selected region;
- the label gives the region’s name and one short description of its function;
- an optional `查看示範` action shows the relevant interaction in the replica.

The user can explore the four regions in any order. A `按順序介紹` mode can guide them through all four, with a small progress indicator such as `1 / 4`.

The first card should therefore answer “where is each part and what does it do?” Later cards can explain the details of the timeline, node information, original-text area, and AI analysis area.

## Floating-label content

- `導覽列`: switch interface areas, import and export structured data, and adjust display settings.
- `時間與關係圖表`: show the chronological order and relationships among documents and events.
- `原始史料區`: display document metadata, the complete original text, and linked evidence.
- `AI 分析區`: display extracted results for review, correction, acceptance, rejection, or later addition to the chart.

The labels should use plain language first. More specialised terms such as document nodes, event nodes, and AI Skills can appear in the later cards.

## UI principle

Every AI result should visibly retain a route back to the original quotation. The demonstration should make the review action more important than the generated card itself.

## Useful controls

- `顯示標註` / `隱藏標註` for hotspot labels.
- `按順序介紹` / `自由探索` to switch between guided and self-directed modes.
- `重播示範` for the guided sequence.
- `重設視圖` to return the replica to its unselected state.
- A small legend for `原始文書`, `AI 候選`, and `研究者確認`.

## Replica requirements

- Use the sample review-tool layout and terminology rather than a generic dashboard mockup.
- Keep the replica large enough for the four regions to remain visible at once.
- On small screens, transform the four highlights into a numbered list while retaining the same click-to-label behaviour.
- If the replica is interactive or live, preserve the distinction between a teaching demonstration and the actual research state.
