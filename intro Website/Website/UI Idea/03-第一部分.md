# UI ideas — 第一部分

## Purpose

Explain the platform’s interface by letting the student recognise the main regions before reading detailed terminology.

## Proposed experience

Start with a full interface image or live sample tool. Add four numbered hotspots:

1. 導覽列
2. 時間與關係圖表
3. 原始史料區
4. AI 分析區

Selecting a hotspot dims the other regions and opens a compact explanation card. A “跟著一份奏摺走” mode can then demonstrate the same document moving from the original-text area to an AI card and finally to a chart node.

## Subsections

- `平台的四大區域`: overview with four hotspots.
- `導覽列`: animated route through input, display switching, notes, and export.
- `時間與關係圖表`: highlight the four lines and distinguish document nodes from event nodes.
- `節點資訊區`: click one node and show its metadata, quotation, and source.
- `原始史料區`: demonstrate original text, metadata, and evidence labels.
- `人工智能分析區`: show accept, edit, reject, and add-to-chart actions.

## UI principle

Every AI result should visibly retain a route back to the original quotation. The demonstration should make the review action more important than the generated card itself.

## Useful controls

- `顯示標註` / `隱藏標註` for hotspot labels.
- `重播示範` for the guided sequence.
- A small legend for `原始文書`, `AI 候選`, and `研究者確認`.
