### L1689｜3.2 文本資訊　`[multi]`

### L1693｜3.3 分段　`[mc]`

- 引導文字（guide）：段落之間要靠什麼來分隔？
- 句子：根據段首的【　】，劃分段落，保留每一段的內容，不要合併不同段落。
- 選項：縮排 / 空行 / 標點符號　正確答案：縮排

### L1697｜3.4 標點符號　`[mc]`

- 引導文字（guide）：標點符號要用全形還是半形？
- 句子：辨識正文的標點符號，所有標點使用【　】，並在輸出 JSON 的最後，標記模糊標點和附近的文句。
- 選項：全形 / 半形　正確答案：全形

### L1701｜3.5 落款與尾批　`[multi]`

- 引導文字（guide）：正文結束後的日期與尾批，應該怎麼處理？
- 句子：正文結束後包含：［官員上奏日期、皇帝硃批日期、尾批］，請分別保存，不要混入正文。
- 需全部勾選項目：官員上奏日期、皇帝硃批日期、尾批　(inline 樣式)

### L1705｜3.6 頁碼　`[choice]`

- 句子（答對後組成）：辨識每一頁角落的頁碼，保留於獨立欄位，不要納入正文。
- 按鈕選項：保留 / 不保留　正確答案：保留

### L1749｜一 · 安裝工具　`[chip]`

- 建議句子（chip，點擊後直接送出）：請在我的電腦上下載並安裝 PaddleOCR。

### L1752｜二 · OCR 目的　`[chip]`

- 引導文字（guide）：再告訴它要辨識哪一份檔案。剛才下載的檔案就在你的電腦裡。
- 建議句子（chip，點擊後直接送出）：然後對名為 try-handwritten.pdf 的檔案進行 OCR，請在我的電腦上搜尋這個檔案。

### L1755｜三 · 版面要求　`[advance]`

- 引導文字（guide）：接下來，請觀察PDF的版面，再向AI指定OCR的規則。
- （點卡片繼續，沒有 prompt 內容）

### L1757｜四 · 版面要求：閱讀順序　`[mc]`

- 引導文字（guide）：手寫奏摺同樣是直排。先把閱讀順序講清楚，否則整段文字會顛倒。
- 句子：奏摺用直排書寫，請按照【　】、由上至下的順序輸出文字，而非由左至右。
- 選項：由右至左 / 由左至右 / 由下至上　正確答案：由右至左

### L1761｜五 · 版面要求：上奏官員　`[mc]`

- 引導文字（guide）：左邊反白的首行，寫著這份奏摺是誰上的。這兩項資料要分開存。
- 句子：奏摺首行標有上奏官員的【　】，例如「福建水師提督　黃仕簡」，請分別獨立標記。
- 選項：官職與姓名 / 籍貫與年齡 / 品級與俸祿　正確答案：官職與姓名

### L1765｜六 · 版面要求：小字自稱　`[mc]`

- 引導文字（guide）：正文中的「奴才」「臣」寫得比別的字小。字小不代表不重要——它們屬於哪裡？
- 句子：正文中的「奴才」或「臣」以較小字體書寫，但仍屬【　】，請保留於原有位置，不要省略或刪除。
- 選項：正文的一部份 / 註釋 / 裝飾文字　正確答案：正文的一部份

### L1769｜七 · 版面要求：硃批　`[mc]`

- 引導文字（guide）：翻到第二頁。紅色的草書是皇帝的硃批，OCR 幾乎辨不準。這一步該怎麼處理？
- 句子：請【　】紅色的硃批草書文字。
- 選項：不要 OCR / 優先 OCR / 合併進正文　正確答案：不要 OCR

### L1773｜八 · 版面要求：印章與浮水印　`[mc]`

- 引導文字（guide）：印章和博物院的浮水印都不是文本內容，別讓它們混進結果裡。
- 句子：請【　】「國立故宮博物院」的浮水印，以及正文後的印章。
- 選項：忽略 / 辨識為正文 / 翻譯　正確答案：忽略

### L1777｜九 · 輸出要求　`[mc]`

- 引導文字（guide）：最後一項要求：辨識完的東西要用什麼格式存下來？回想一下第 9 步說過的結構化格式。
- 句子：最後，請把以上所有結果輸出為【　】 格式，以「欄位－內容」的方式儲存，方便後續讀取與分析。
- 選項：JSON / TXT / DOCX　正確答案：JSON

### L1781｜十 · 你自己的要求　`[free]`
