01 / INTRODUCTION

兩種官方通信

奏摺、硃批與上諭如何共同記錄清代政治溝通？

奏摺保存地方官員向皇帝呈報的資訊；硃批與上諭則保存皇帝的回應、命令和判斷。它們不是孤立的文本，而是同一個中央與地方通信網絡中的不同環節。

02 / PLATFORM

AI 先提取，
人再判斷。

每項結果都要帶有原文引文和來源資料。

人工智能把長篇文本轉成結構化候選結果，再由研究者回到原文核對、保留、拒絕或修改。只有通過核驗的結果，才會進入圖表。

03 / REUSE

一套流程，
多個題目。

由新史料到新網站的 AI 處理循環。

研究者可以準備新的文本、轉換為 JSON、調整 Skills，然後以 Python 和 AI API 逐份執行，再把中間結果載入網站核驗。這個框架可延伸到戰爭、司法、災害、外交及地方行政等題目。
